# Academic Website

This is a Quarto academic website designed to be hosted on GitHub Pages.

## Replace these files

- `index.qmd` — homepage
- `research.qmd` — research projects
- `publications.qmd` — publications and working papers
- `teaching.qmd` — teaching
- `cv.qmd` — CV
- `contact.qmd` — contact information
- `images/headshot.jpg` — your photo
- `files/CV.pdf` — your CV

## Important

Replace `YOURDOMAIN.com` in `_quarto.yml` and `CNAME` with your actual domain.

Replace `YOURUSERNAME` with your GitHub username.

## Publishing

The included GitHub Action automatically builds and publishes the Quarto site whenever you push to `main`.
